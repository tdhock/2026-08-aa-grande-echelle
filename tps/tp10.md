Le but de ce TP est de soumettre un Pull Request (en anglais) avec un nouveau Learner dans mlr3extralearners.

[Inscrivez-vous ici](https://github.com/tdhock/2026-01-aa-grande-echelle/wiki/projets) pour que chacun travaille sur un sujet différent.

# Démarche

* Cliquer sur [mlr3extralearners Fork](https://github.com/mlr-org/mlr3extralearners/fork) pour créer votre copie du projet.
* Obtenir une copie sur votre machine, `git clone` de `vous/mlr3extralearners`, pas `mlr3-org/mlr3extralearners`.
* Créer une nouvelle branche pour vos modifications, `git checkout -b nom_branche`.
* Ajouter code + documentation + tests pour votre Learner (même que dans le TP9).
* Faire `git commit` pour sauvegarder les modifications dans la branche.
* Faire `git push` pour envoyer les modifications à votre copie sur GitHub.
* Faire un Pull Request
  * avant le lundi 20 avril, faire un Draft Pull Request
  * écrire une commentaire en demandant une relecture du `@tdhock`
* je vais lire votre soumission et suggerer des améliorations (20 / 21 avril).
* vous allez ensuite réviser, en faisant `git commit` et `git push` (22 / 23 avril), et cliquer sur « Ready for review » pour indiquer que c’est prêt pour relecture par les développeurs du projet.

# PDF à soumettre

Soumettez votre rapport en fichier PDF (en français ou anglais) avec 

* un lien vers votre Pull Request
* quelques lignes de texte expliquant les révisions que vous avez fait le 22 / 23 avril, suite à mes suggestions.
* suivez [les standards dans la rédaction de code R](https://docs.google.com/document/d/1Mw5Nk9UHEoF_c1b5JqDCdeXP5pX1HPCQ8HSGCsVSw7M)
